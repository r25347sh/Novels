# ラノベ古事記風・日本神話

古事記（712年成立）をベースにした、完全オリジナルの現代ラノベ風再話です。

## 構成

- **トップページ**（`index.html`）  
  「第何話を読みますか？」形式のエピソード選択画面  
  前回の続きから読めるバナー付き

- **各話1ページ**（`episodes/01.html` 〜 `14.html`）  
  カクヨム風の読みやすいビューア

## 特徴

- HTML / CSS / JavaScript 完全分離
- 文字サイズ変更（小・中・大・特大）
- 背景テーマ（ライト / セピア / ダーク）
- localStorage による最終閲覧位置の保存  
  → **開いてから約8秒経過後にのみ保存**（誤って開いた場合は保存されない）
- 次回アクセス時に「続きを読む」表示

## 使い方

1. `index.html` をブラウザで開く
2. 読みたい話を選ぶ（または「続きを読む」）
3. 各話ページで「ぁあ」ボタンから表示設定可能

## 出典・著作権表記

- **原典**：古事記（太安万侶 撰、和銅五年＝712年成立）
- 本作品はパブリックドメインの神話を元にした**完全オリジナルの現代ラノベ風再話**です
- 特定の現代語訳サイトや市販書籍の文章を複製・翻案したものではありません
