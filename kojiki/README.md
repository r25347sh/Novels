# ラノベ古事記風・日本神話

古事記（712年成立）をベースにした、完全オリジナルの現代ラノベ風再話です。

## 特徴

- **HTML / CSS / JavaScript 完全分離**
- カクヨム風の読みやすいビューア
  - 文字サイズ変更（小・中・大・特大）
  - 背景テーマ（ライト / セピア / ダーク）
  - 目次サイドバー
  - 前へ / 次へ ナビゲーション
- **localStorage による最終閲覧位置の保存**
  - 開いてから約8秒経過後にのみ保存（誤って開いた場合は保存されない）
  - 次回アクセス時に自動で続きから開く
- 神社検定対策にも使えるよう、主要な神名・出来事は正確に記載
- 娯楽として読めるテンポの良い語り口

## 構成

- **上巻・神代**：天地開闢〜海幸山幸
- **中巻・天皇記**：神武東征〜神功皇后・応神
- **下巻・天皇記**：仁徳〜雄略など
- **終章**：まとめと出典

## 使い方

1. `index.html` をブラウザで開くだけ（ローカルでも動作します）
2. 左上の ☰ で目次を開く
3. 「ぁあ」ボタンで表示設定
