# 特界シリーズ　世界観・組織設定

最終更新：2026年8月12日

---

## 1. 基本世界構造

### 階層構造

```
特界（上）
───────（境界線）───────
通界（下）
```

- **特界**  
  通界全体を上から管理・監視する上位領域。  
  ここに各種役所が存在する。

- **通界**  
  実際の「異世界」たちが存在する領域。  
  通界の中には複数の「世界」が存在する。

### 通界内の1つの世界の構造

1つの「世界」は以下のように構成される：

```
【オモテ】
・天界（神々などがいる）
・人界（人間が暮らす）

【ウラ】
・魔界
```

- 天界と人界は上下関係にある（天界の方が上位）。
- 魔界は天界・人界の「裏側」に位置する。
- 天界・人界・魔界の間は「基本的に」出入りできない。
- 通界から特界への出入りも「基本的に」できない。
- 魔界は通界の中にある世界の一部に過ぎず、人界と扱いに差はない。

### 重要な原則

- 通界には「世界①」「世界②」……と複数の世界が存在する。これが一般的に言う「異世界」の正体。
- 特界はそれら複数の世界をまとめて管理している。
- 「基本的に出入りできない」が原則だが、**例外**が存在する。

## 2. 特界の組織構造

### 基幹組織（5つ）

1. **転生輪廻管理局**  
   魂の回収、転生先の割り当て、勇者・英雄の召喚（勇者ガチャ）、輪廻システムの維持などを担当。

2. **因果調整庁**  
   運命・因果の歪みの修正、歴史改変の監視、大きな事件の事後処理などを担当。エリート意識が強い。

3. **境界警備局**  
   特界と通界の境界、および各世界間の不正出入国を取り締まる。公安・警察的な雰囲気。

4. **神務省**  
   天界の神々との窓口。神々からの依頼・クレーム・無理難題の受付と調整を担当。

5. **特界総務院**  
   特界全体の人事・予算・施設管理・内部事務を名目上統括する役所。  
   **実態は「特界の何でも屋」**。

### 特界総務院の性格

- 名前は立派だが、実態は他部署が「うちの管轄じゃない」と放り投げた案件を全部押し付けられる何でも屋。
- 人手不足で、一人が何役も兼任している。
- 権限はあるように見えて、実際には調整役に回されることが多い。
- 「総務院に言っとけば何とかなるだろ」と他部署から雑に扱われる。

### 特界総務院の内部構成

- **総合調整室**  
  名目上の中枢。実際の仕事は他部署から放り投げられた案件の火消しと部署間の調整。

- **例外審査会事務局**  
  境界を越えてきた者や、規定外の案件を審査する委員会の実務を担当。

- **記録保管庫（アーカイブ）**  
  特界のあらゆる記録を保管・管理する部署。

- **歪み対策室**  
  通界に出現する「どの世界にも属さない歪み」の対処を専門に行う部署。  
  表向きは小さくて地味だが、扱う案件の性質上、重要な情報に触れやすい。

- **施設・備品管理係**  
  特界内の建物や設備の管理。

- **臨時対応班**  
  人が足りないときに急遽編成される何でも担当。

## 3. 主人公設定（暫定）

### 基本情報

- **出自**：通界のどこかの世界（人界）出身。
- **見た目**：普通の人間と変わらない。
- **立場**：特界総務院の正式な職員（ただし経歴が特殊）。
- **なぜ特界にいるのか**：明確な「例外」を経由して来た。本人も最初は理由をよくわかっていない。
- **現在の立ち位置**：入局して間もない新人。

### 配属先

- **名刺上**：特界総務院　総合調整室
- **実態**：人手不足のため、臨時対応班的な動きを強いられている。  
  部署の枠を超えて、特界全体の案件を横断的に担当する。

### 仮名

- 青葉 透（あおば とおる）※仮。性別は一旦男性で進行。後で変更可能。

## 4. 作品の方向性

- シリーズ化を前提とする。
- 特界のさまざまな役所を舞台にした物語を展開する予定。
- トーンはブラックお役所コメディ寄り。  
  廣嶋玲子さんの『十年屋』『彩屋』的な「普通の感覚を持った人間が、普通じゃない場所に適応していく」雰囲気を意識する。
- 第一話の具体的な内容は未定（以前の書き出しは一旦破棄）。
